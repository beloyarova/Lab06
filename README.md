# ПР6. Ответы на контрольные вопросы

1. Чем void-метод отличается от метода, объявленного с типом возврата (например, int)?

void-метод ничего не возвращает он просто выполняет действия

Метод с типом (int, bool и другие) возвращает результат с помощью return

2. Что происходит с выполнением метода в момент срабатывания return?

Метод сразу заканчивает работу. Код после return не выполняется

3. Что такое перегрузка методов и по каким признакам компилятор выбирает нужную перегрузку при вызове?

Это несколько методов с одним именем, но разными параметрами. Компилятор сам выбирает нужный по аргументам

4. Можно ли перегрузить метод, если у двух версий совпадают все параметры, а различается только тип возвращаемого значения? Почему?

Нельзя. При вызове параметра компилятор выбирает метод только по аргументам. Если параметры одинаковые, возникает ошибка компиляции

5. Приведите свой пример (не из этой работы), когда логично разбить один большой кусок кода на два отдельных метода.

До пустим один метод проверяет правильно ли введён возраст, другой метод печатает сообщение. Так код понятнее и его можно использовать повторно

6. Что означает, когда один метод вызывает внутри себя другой метод? Как это связано с идеей переиспользования кода?

Когда метод вызывает другой метод он использует уже написанный код. Это позволяет избежать многократного копирования строк достаточно написать метод один раз и вызывать его при необходимости. Это и называется переиспользованием кода
